# Changelog

## 0.5.0

- Wayline identity and new application icons.
- Separate connection, chain, Xray and log views, including advanced options on Android.
- Profile rename and reliable name persistence.
- Xray names preserved during import, named cards, endpoint editors and complete JSON settings.
- Clear/copy logs.
- Per-app VPN include/exclude routing with searchable app pickers.
- Explicit certificate Proceed action with optional remembered fingerprints per profile.

## 0.4.0

- Wayline branding and independent application identifiers.
- Named Xray configurations with checkboxes, deletion and ordered Before/After hops.
- Opt-in automatic reconnect with cancellation and backoff.
- Android session isolation, larger packet buffers, nonblocking TUN I/O and throughput readings.
- Windows per-user startup option.
- Android ARM64 and ARMv7 build support.
- Ubuntu/Debian desktop and headless clients.
- Blank profiles and release scans for local credentials and metadata.
