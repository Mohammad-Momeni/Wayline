# Wayline for Windows

Install the .NET 8 Desktop Runtime, extract the full Windows ZIP and open Wayline.exe. See the root README and BUILDING.md for profiles, chaining and source builds.

Saved profiles are per-user and passwords use Windows Credential Manager. All connection fields start blank. Enable Start with Windows only after placing the executable in its permanent location; it opens minimized at login. Auto reconnect is optional. VPN mode requires elevation.
